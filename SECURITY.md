# Política de segurança

Não publique vulnerabilidades ou credenciais em issues.

Relate problemas pelo recurso privado **Report a vulnerability** na aba **Security**, quando disponível. Se o recurso não estiver habilitado, use um canal de contato indicado no perfil do mantenedor sem publicar os detalhes. Inclua impacto, passos mínimos para reprodução e a versão ou commit afetado; não inclua dados de terceiros.

Credenciais expostas devem ser revogadas imediatamente. Uma limpeza de histórico Git reduz a exposição, mas não substitui a rotação dos segredos.
